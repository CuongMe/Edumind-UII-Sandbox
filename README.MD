| Layer                  | Tech                         | Purpose                                                                                                                                                                         |
| ---------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Frontend + backend** | **Next.js + TypeScript**     | One web app with pages and API routes in the same project. Vercel has first-class Next.js support. ([Vercel][1])                                                                |
| **Hosting**            | **Vercel**                   | Deploy from GitHub, get a live demo link, easy for pitch day.                                                                                                                   |
| **Styling**            | **Tailwind CSS**             | Fast responsive UI for phone and laptop screens.                                                                                                                                |
| **UI components**      | **shadcn/ui + lucide-react** | Clean dashboard cards, buttons, tabs, upload boxes, icons.                                                                                                                      |
| **Database**           | **Supabase Postgres**        | Store students, classes, homework submissions, OCR text, AI feedback, and knowledge gaps. Supabase JS works with Postgres, auth, storage, and files. ([Supabase][2])            |
| **File storage**       | **Supabase Storage**         | Store uploaded homework images. Supabase Storage works with Postgres and client libraries. ([Supabase][3])                                                                      |
| **OCR**                | **Mathpix OCR API**          | Read handwritten/printed math, text, tables, and STEM content from images/PDFs. ([Mathpix Docs][4])                                                                             |
| **AI model**           | **Gemini API Free Tier**     | Generate mistake analysis, Socratic hints, teacher comments, and mini quizzes. New Gemini API accounts start on the Free Tier with rate limits. ([Google AI for Developers][5]) |
| **Validation**         | **Zod**                      | Validate API inputs and outputs.                                                                                                                                                |
| **Charts**             | **Recharts**                 | Teacher dashboard charts: class accuracy, common gaps, progress.                                                                                                                |
| **Version control**    | **GitHub**                   | Connect repo to Vercel for deployment.                                                                                                                                          |
